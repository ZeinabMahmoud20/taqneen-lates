# قايمة التشغيل الفعلي (قبل أول استخدام ببيانات حقيقية)

## 1) إعدادات `.env`
- `APP_ENV=production` و `APP_DEBUG=false` (لو الـ debug شغّال بتظهر للمستخدم تفاصيل داخلية).
- `APP_URL` بالعنوان الحقيقي، و `APP_TIMEZONE=Africa/Cairo`.
- `LOG_LEVEL=warning`.
- مستخدم قاعدة بيانات مخصص للنظام (مش `root`) بصلاحيات على قاعدة `arrears` بس.
- على HTTPS: `SESSION_SECURE_COOKIE=true`.

## 2) بعد كل تحديث للكود
```bash
composer install --no-dev --optimize-autoloader
php artisan migrate --force
php artisan optimize          # بيشغّل filament:optimize معاه
```
ولو حصلت حاجة غريبة بعد التحديث: `php artisan optimize:clear`.

## 3) المستخدمين
- غيّر باسورد حساب `admin` الأول، وسيب حساب مشرف عام تاني احتياطي.
- لكل موظف حساب منفصل بدوره (مشرف عام / مسئول تقنين / قيادة).
- الموظف اللي سابك: **وقف الحساب** (خانة «الحساب مفعّل») بدل ما تحذفه، علشان اسمه يفضل ظاهر في سجل العمليات.
- ماتديش دور «مشرف عام» إلا للي محتاجه فعلاً (هو الوحيد اللي يحذف ويلغي السداد ويشوف سجل العمليات).

## 4) التوقيت
المتأخر بيتحسب بتاريخ سيرفر MySQL (`CURDATE()`). لازم نظام التشغيل (وبالتالي MySQL) يكون على توقيت القاهرة، وإلا قسط ممكن يظهر متأخر قبل أو بعد معاده بيوم.

## 5) الشبكة
- HTTPS إجباري لو النظام متاح برا الشبكة الداخلية.
- منفذ MySQL (3306) مايتفتحش للإنترنت.

## 6) النسخ الاحتياطي
- شغّل `scripts/backup-database.bat` (أو جدوله في Task Scheduler يومياً).
- **جرّب الاسترجاع مرة واحدة على الأقل** على قاعدة تجريبية:
  `mysql -u root -e "CREATE DATABASE arrears_restore CHARACTER SET utf8mb4"` ثم
  `mysql -u root --default-character-set=utf8mb4 arrears_restore < ملف_النسخة.sql`
- النسخة الاحتياطية بتحتوي بيانات مالية وشخصية: خزّنها في مكان محمي.

## 7) اختبار قبل الاعتماد
1. `php artisan test` (على قاعدة اختبار `arrears_test` المنفصلة).
2. استيراد الملف الحقيقي بـ «تحقق فقط» ومراجعة التنبيهات والأخطاء.
3. بعد الاستيراد الفعلي: قارن عدد العقود وعدد الأقساط المسددة بالإكسيل، وراجع 5 عقود عشوائية قدام الأصل.
4. جرّب كل دور (مشرف عام / مسئول تقنين / قيادة) وتأكد إن كل واحد يشوف ويعمل اللي يخصه بس.
